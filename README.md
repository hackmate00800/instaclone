# Instagram Clone

A modern Instagram clone built with React, Vite, and Tailwind CSS.

## Features

- ✅ Home feed with posts and stories
- ✅ User profiles with posts grid
- ✅ Direct messaging
- ✅ Explore page
- ✅ Notifications
- ✅ Create posts
- ✅ Like, comment, save posts
- ✅ Follow/unfollow users
- ✅ Authentication (Login/Register)
- ✅ Responsive design
- ✅ Real-time updates (simulated)
